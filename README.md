# OW Team Selector (オーバーウォッチ チームセレクター)

オーバーウォッチ (Overwatch) のカスタムマッチやスクリム、内戦で利用できるチーム分け・マップ抽選ツールです。  
HTMLファイル1つで動作するため、ブラウザで開くだけで手軽に利用できます。

---

## 🌟 主な機能

- **チーム分け＆観戦自動割り当て**
  - プレイヤー名を1行ずつ入力してボタンを押すだけで、TEAM 1・TEAM 2・観戦（SPECTATORS）に自動で振り分けます。
  - **連続観戦防止ロジック**: 11名以上でプレイする場合、直近で観戦だったプレイヤーが連続で観戦にならないよう内部でカウント・配慮して抽選されます。
- **ロール自動割り当て**
  - 「ロール割り当てを有効化」にチェックを入れると、各チームに **タンク1名 / ダメージ2名 / サポート2名** をランダムに割り当てます。
- **マップ抽選機能**
  - ハイブリッド、ペイロード、コントロール、プッシュ、フラッシュポイントの各ルールに対応（新マップ「Neon Junction」等も収録）。
  - モードごとのオン/オフ設定や個別のマップ除外設定が可能です。
  - **マップ重複防止**: 直近に選ばれたマップ（最大3マップ）は連続で選ばれない仕様になっています。
- **プレイヤー名の自動保存（ローカルストレージ）**
  - 入力したプレイヤー名はブラウザ内に自動的に保存されます。ページを閉じたり更新したりしても、次回アクセス時に前回のメンバー名が残っているため再入力の手間が省けます。
- **Discord連携**
  - チーム分け結果とマップ選択結果をDiscordで見やすいマークダウン形式テキストとしてワンクリックでコピーできます。

---

## ⚙️ 使い方

1. `index.html` をブラウザで開きます。
2. プレイヤー名を1行に1名ずつ入力します。
3. **「チーム分け実行」** ボタンを押してチームを生成します。
4. **「マップ抽選」** ボタンを押してプレイするマップを決定します。
5. **「結果をコピー」** ボタンを押すと、Discordに貼れるフォーマットで結果がクリップボードに保存されます。

---

## 🧹 データのリセットについて

- **入力欄・保存名のクリア**
  - **「入力リセット」** ボタンを押すと、入力欄のテキストおよびブラウザに保存されたプレイヤー名データが削除されます。
- **観戦・チーム分け履歴の初期化**
  - 「連続観戦防止」などの内部履歴は、**ページの再読み込み（リロード）** を行うことで完全にリセットされます。メンバーを総入れ替えして完全に最初からやり直したい場合は、ページをリロードしてご利用ください。
